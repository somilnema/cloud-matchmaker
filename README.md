# Tata Matchmaker: AI-Powered Strategic Synergy Engine

A high-fidelity Next.js 14 application designed for the Tata Group to match business requirements with optimal ecosystem divisions.

## Features
- **Dynamic AI Quiz**: 10 adaptive questions powered by Gemini 2.0 Flash.
- **Neural Reasoning**: Real-time AI logic visualization during the quiz.
- **Voice Synthesis**: Professional "Strategist" voice-over for all questions.
- **Interactive Results**: side-by-side dashboard with Neural Synergy Mapping.
- **Strategic PDF Export**: Professional report generation for executive review.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS + Framer Motion
- **AI**: Google Gemini 2.0 Flash (via OpenRouter)
- **Icons**: Lucide React

## Getting Started
1. Clone the repository.
2. Install dependencies: `npm install`.
3. Set `OPENROUTER_API_KEY` in `.env.local`.
4. Run development server: `npm run dev`.
